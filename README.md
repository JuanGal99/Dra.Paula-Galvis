# Dra. Paula Galvis

Landing page bilingüe de la Dra. Paula Galvis, ortodoncista en Colombia, orientada a captar pacientes de Estados Unidos y de otros países interesados en combinar tratamiento dental y turismo.

## Características

- Sitio en inglés y español, con HTML generado para cada idioma.
- Secciones de perfil profesional, servicios, turismo dental y contacto.
- Formulario de contacto con validación, protección antispam y autorización de tratamiento de datos conforme a la Ley 1581 de 2012.
- Contacto directo por WhatsApp, con conteo de clics por día e idioma sin cookies.
- Datos estructurados, Open Graph, hreflang y sitemap para buscadores y redes sociales.
- Imágenes en WebP y fuentes alojadas en el propio sitio.

## Tecnologías

React 19, TypeScript, Vite, Tailwind CSS 4, i18next, Formspree y Netlify Functions con Netlify Blobs.

## Estructura

```text
netlify/functions/   Contador de clics de WhatsApp
public/              Imágenes, íconos, robots.txt y sitemap.xml
scripts/             Generación del HTML de cada idioma
src/components/      Secciones de la página
src/locales/         Textos en inglés y español
```
